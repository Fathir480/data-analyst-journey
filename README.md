# Data Analyst Journey

Perjalanan belajar saya menuju Data Analyst, dari tes level awal sampai proyek portofolio. Repo ini mencatat apa yang dipelajari, apa yang tadinya salah paham, dan hasil akhirnya.

## Isi repo
- `catatan-mingguan/`: ringkasan belajar tiap minggu dengan bahasa sendiri
- `latihan/`: notebook latihan (NumPy, Pandas, SQL, visualisasi, statistik)
- `proyek/`: proyek analisis lengkap dengan README masing-masing

## Roadmap (12 minggu)
1. NumPy: shape, axis, broadcasting
2. Pandas: groupby, merge, data kosong
3. SQL dasar
4. SQL lanjut: JOIN, subquery
5. Visualisasi + statistik deskriptif
6. Statistik untuk analis + tes ulang
7. Dashboard (Looker Studio)
8. Alur analisis dan bercerita dengan data
9-10. Proyek 1
11-12. Proyek 2
